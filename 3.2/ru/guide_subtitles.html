Субтитры

Субтитры — единственная часть библиотеки, где не используется API кодеков send/receive. FFmpeg до сих пор предоставляет кодеки субтитров через устаревшие avcodec_decode_subtitle2() и avcodec_encode_subtitle(), и avcpp это повторяет: у SubtitleCodecContext поэтому нет send(), receive() и flush().

Декодирование

std::size_t packets = 0;
std::size_t frames = 0;
av::Packet pkt;
while ((pkt = ictx.readPacket(ec))) {
if (pkt.streamIndex() != sst.index())
continue;
++packets;
std::size_t decodedBytes = 0;
auto frame = dec.decode(pkt, 0, decodedBytes, ec);
if (ec) {
std::cerr << "Can't decode a subtitle: " << ec.message() << '\n';
return 1;
}
// A packet can be consumed without producing a complete subtitle.
if (!frame)
continue;
++frames;
std::cout << "subtitle " << frames
<< ": pts " << frame.pts()
<< " (" << frame.pts().seconds() << " s)"
<< ", display " << frame.startDisplayTime()
<< ".." << frame.endDisplayTime() << " ms"
<< ", rects: " << frame.numRects() << '\n';
for (std::size_t i = 0; i < frame.numRects(); ++i)
printRect(frame.rect(i), i);
}

Две детали отличаются от видео:

  • decode() принимает смещение и заполняет выходной параметр decodedBytes. Пакет может быть израсходован, не дав полного субтитра, и тогда возвращенный кадр пуст. Это нормально, а не ошибка, и цикл просто продолжается.
  • Кадр несет startDisplayTime() и endDisplayTime() в миллисекундах относительно своего pts(). Оба значения беззнаковые и могут быть нулевыми, а pts() + startDisplayTime() — абсолютное время показа в базе времени кадра.

В av::SubtitleFrame до numRects() прямоугольников. Каждый прямоугольник одного из трех видов:

Тип Содержимое Методы
SUBTITLE_TEXT простой текст text()
SUBTITLE_ASS строка диалога ASS ass()
SUBTITLE_BITMAP растровое изображение с палитрой width(), height(), x(), y(), nbColors()

isForced() помечает прямоугольники, которые показывают даже при выключенных субтитрах. У растровых прямоугольников есть и палитра; см. справочник av::SubtitleRect.

Кодирование

SubtitleEncoderContext строже декодера:

  1. Вызовите setSubtitleHeader() (или setDefaultSubtitleHeader()) до open().
  2. Передавайте только прямоугольники SUBTITLE_ASS с startDisplayTime() == 0. Текстовые и растровые кодировщики FFmpeg отклоняют все остальное, а ненулевое время начала — не то, чего ждет кодировщик: время несет метка кадра.
  3. Используйте один кадр на одно событие субтитра и задайте на нем pts() и базу времени.

Практичен путь ASS: кодировщик вроде ass или subrip принимает строку диалога без тегов оформления, которые он не поддерживает. Если на входе SRT, а на выходе нужен ASS, декодируйте в прямоугольники SUBTITLE_TEXT и соберите строку ASS сами — автоматической конвертации в библиотеке нет.
