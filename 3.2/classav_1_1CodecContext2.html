Detailed Description

Send/receive contract
The send/receive API wraps the FFmpeg send/receive model:
  • send() submits one packet (decoding) or one frame (encoding) and returns false when the codec cannot accept more input until the output is drained. This EAGAIN condition is not an error.
  • receive() returns one output object. An empty (invalid) result means that no output is available yet (EAGAIN) or that the stream has ended.
  • After the last input, call flush() once and keep calling receive() until it returns an empty result. At that point isEof() becomes true.
  • An empty result is never marked as complete. Callers must check the object with operator bool() or isNull()/isValid().
  • flushBuffers() resets the codec state and the EOF flag, for example after a seek back to a key frame.
