Detailed Description

Every public type and function lives in av, usually as a thin RAII wrapper over the corresponding FFmpeg type. Wrappers do not copy data unless the documentation of the specific method says so; ownership and lifetime are stated per class and per method.

Call av::init() before anything else.

◆ AvioInterruptCb

using av::AvioInterruptCb = std::function<int()>

The callback runs periodically while FFmpeg waits on a socket. A non-zero result interrupts the read or write and surfaces as an FFmpeg error, which is how a stalled network source is made cancellable.
