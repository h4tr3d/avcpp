Detailed Description

The frame can live in system memory, where data[] is readable, or in device memory, where it is only a descriptor for a hardware surface; isHwFrame() tells the two apart and toSystemMemory() moves between them.

Examples
api2-decode-filter-encode.cpp, api2-decode-overlay-encode.cpp, api2-decode-raw-h264.cpp, api2-decode.cpp, api2-hw-decode.cpp, api2-hw-encode.cpp, api2-hw-scale.cpp, and api2-hw-transcode.cpp.

VideoFrame av::VideoFrame::toSystemMemory ( PixelFormat format = AV_PIX_FMT_NONE,

The function allocates a software frame and copies the hardware surface into it. When format is not AV_PIX_FMT_NONE, the transfer requests that format. The format must be supported by the hardware backend; see FramesContext::transferFormats().

A software frame is returned as a reference copy when no format conversion is requested.
