SubtitleFrame av::SubtitleDecoderContext::decode ( const Packet &  packet,
OptionalErrorCode  ec = throws() 
)

Decodes one subtitle packet.

The returned frame owns its rectangles. AVSubtitle has no reference counting, so every call returns a newly allocated frame.

The frame pts is in AV_TIME_BASE units. It is filled when pktTimeBase() or the packet/stream time base is available; otherwise pts() reports NoPts.

An invalid frame means that the packet did not produce a subtitle yet (for example, a decoder that buffers partial data).
