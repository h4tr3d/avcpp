std::string_view av::subtitle::defaultAssHeader ( )
noexcept

Returns a built-in ASS/SSA script header accepted by the FFmpeg text subtitle encoders (subrip, webvtt, mov_text, text and ass).

The value does not depend on the FFmpeg version, unlike the headers generated by the FFmpeg subtitle decoders.
