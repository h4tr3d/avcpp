Detailed Description

Owning, move-only subtitle frame.

Wraps AVSubtitle. AVSubtitle has no reference counting API in FFmpeg, so copies are disabled; use clone() for an explicit deep copy.

The pts value is interpreted in AV_TIME_BASE units, as required by FFmpeg. The default time base is 1/AV_TIME_BASE; setTimeBase() rescales the stored pts value.
