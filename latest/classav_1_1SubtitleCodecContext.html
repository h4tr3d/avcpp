Detailed Description

template<typename Clazz, Direction _direction>
class av::SubtitleCodecContext< Clazz, _direction >

Subtitle codecs use the legacy avcodec_decode_subtitle2() / avcodec_encode_subtitle() functions. The FFmpeg send/receive API aborts for subtitle codecs, so send(), receive() and flush() are deleted here and the generic CodecContext2 implementations report Errors::CodecUnsupportedOperation.

Text subtitle encoders (subrip, webvtt, mov_text, text) require a subtitle header before open(); use setDefaultSubtitleHeader() for a built-in ASS header. Bitmap encoders such as dvdsub do not need one.
