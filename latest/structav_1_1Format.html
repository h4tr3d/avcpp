Detailed Description

template<typename T>
struct av::Format< T >

The template is instantiated with the const or non-const FFmpeg type, depending on how old the FFmpeg headers are, so the same code compiles against both.

Template Parameters
TAVInputFormat or AVOutputFormat, possibly const
