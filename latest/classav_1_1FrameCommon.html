Detailed Description

Owns an AVFrame and adds the avcpp bookkeeping that FFmpeg keeps outside it: the time base, the stream index and a completeness flag. Derived classes are expected to implement assignment through assignOperator()/moveOperator(); direct assignment is deleted here to make slicing impossible.

Reference counting follows AVPacket/AVFrame semantics: a copy of the wrapper references the same frame buffer, and clone() is the way to get an independent copy.
