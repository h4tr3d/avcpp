Detailed Description

A stream is a view: it points into the AVFormatContext that owns the AVStream, so it must not outlive that context. Copying a Stream is cheap and does not copy any stream data.

Every value here has meaning only after FormatContext::findStreamInfo(): a container read only far enough to list its streams reports incomplete codec parameters and zeroed timings.
