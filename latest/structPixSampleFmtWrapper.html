Detailed Description

template<typename WrapperClass, typename T, T NoneValue = static_cast<T>(-1)>
struct PixSampleFmtWrapper< WrapperClass, T, NoneValue >

The concrete wrappers (PixelFormat, SampleFormat) add name lookup and comparison; this template supplies the storage and the conversions that let a wrapper be passed wherever FFmpeg expects the raw enum.
