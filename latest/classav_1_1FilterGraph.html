Detailed Description

Build it in one of two ways: parse() a textual description such as "scale=320:240,format=yuv420p", or add filters by hand with createFilter() and link() them. config() negotiates the formats and allocates the internals; nothing can be pushed before it succeeds.

The graph owns every context created through it, so contexts must not outlive the graph.

Examples
api2-decode-filter-encode.cpp, and api2-decode-overlay-encode.cpp.
