Detailed Description

Lazy range that probes every compiled device type.

A probe creates a temporary device context and destroys it immediately. Availability is reported per type. Creation is the only reliable check: av_hwdevice_iterate_types() lists compiled backends, not present hardware.

Parameters
deviceBackend-specific device selector passed to av_hwdevice_ctx_create(). It is a string and not std::filesystem::path on purpose: the value identifies a device, and it is not necessarily a node in the filesystem. Depending on the backend it can be:
  • a filesystem path (VAAPI, DRM: "/dev/dri/renderD128");
  • a numeric index (CUDA: "1");
  • a display or adapter name (D3D11VA, VideoToolbox);
  • an empty string or nullptr for the default device. A path type would wrongly imply a filesystem node and cannot represent the other forms.
Note
The const char* overload borrows the pointer. The caller must keep the string alive for the whole iteration. The std::string overload stores a copy inside the range.
