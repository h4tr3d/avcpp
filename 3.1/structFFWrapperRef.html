Detailed Description

template<typename T>
struct FFWrapperRef< T >

Used for structures FFmpeg expects to be passed by pointer but that have no separate allocation, such as AVPacketSideData. Address stability is part of the contract: raw() returns a pointer into the wrapper, so the wrapper must outlive any FFmpeg call that uses it.
