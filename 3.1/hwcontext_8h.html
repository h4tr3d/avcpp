◆ probeDevices() [1/2]

DeviceProbeRange av::hw::probeDevices ( const char * device = nullptr)

Each step creates a device and destroys it immediately, which is the only reliable availability check: FFmpeg lists compiled backends, not hardware.

Parameters
devicebackend-specific selector, for example "/dev/dri/renderD128" or "1"; nullptr asks for the default device
Returns
a lazy range of results; the selector must outlive the range
