Detailed Description

It has size same to the AVPixelFormat, but wrap pixel description function too. Pixel format descriptor.

A thin wrapper over AVPixelFormat that can answer the questions a pipeline asks: the name of the format, how many planes it has, how many bits per pixel it needs, and what a conversion to another format would cost.

Examples
api2-hw-decode.cpp, api2-hw-encode.cpp, and api2-hw-probe.cpp.
