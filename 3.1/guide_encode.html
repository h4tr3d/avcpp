Encoding

Encoding takes frames and produces packets. The setup is longer than decoding, because the output has to be described: which container, which codec, which resolution, which time base. After that, the loop is short.

Setup

OutputFormat ofrmt;
FormatContext octx;
ofrmt.setFormat(string(), out);
octx.setFormat(ofrmt);
Codec ocodec = findEncodingCodec(ofrmt);
VideoEncoderContext encoder {ocodec};
// Settings
encoder.setWidth(vdec.width());
encoder.setHeight(vdec.height());
if (vdec.pixelFormat() > -1)
encoder.setPixelFormat(vdec.pixelFormat());
encoder.setTimeBase(Rational{1, 1000});
encoder.setBitRate(vdec.bitRate());
encoder.open(Codec(), ec);
if (ec) {
cerr << "Can't opent encodec\n";
return 1;
}
Stream ost = octx.addStream(encoder);
ost.setFrameRate(vst.frameRate());
octx.openOutput(out, ec);
if (ec) {
cerr << "Can't open output\n";
return 1;
}
octx.dump();
octx.writeHeader();
octx.flush();

Three objects are involved:

  • av::OutputFormat names the container. setFormat(string(), out) fills it from the output file name; constructing it with an explicit name forces a container that the extension does not imply.
  • av::FormatContext owns the output. setFormat() must happen before addStream().
  • av::VideoEncoderContext is built from the codec returned by findEncodingCodec(). Some codecs need more than the parameters above — see Hardware decoding and encoding for the hardware cases and the frame-rate requirement of QSV.

Order matters. open() the encoder before addStream(), and openOutput() after the streams exist, because the muxer needs to see them. writeHeader() starts the container; dump() is a diagnostic that prints the stream layout and is safe to remove.

The loop

do {
// DECODING
auto frame = vdec.decode(pkt, ec);
count++;
//if (count > 200)

bool flushEncoder = false;
if (ec) {
cerr << "Decoding error: " << ec << endl;
return 1;
} else if (!frame) {
//cerr << "Empty frame\n";
//flushDecoder = false;
//continue;
if (flushDecoder) {
flushEncoder = true;
}
}
if (frame) {
clog << "Frame: pts=" << frame.pts() << " / " << frame.pts().seconds() << " / " << frame.timeBase() << ", " << frame.width() << "x" << frame.height() << ", size=" << frame.size() << ", ref=" << frame.isReferenced() << ":" << frame.refCount() << " / type: " << frame.pictureType() << endl;
// Change timebase
frame.setTimeBase(encoder.timeBase());
frame.setStreamIndex(0);
frame.setPictureType();
clog << "Frame: pts=" << frame.pts() << " / " << frame.pts().seconds() << " / " << frame.timeBase() << ", " << frame.width() << "x" << frame.height() << ", size=" << frame.size() << ", ref=" << frame.isReferenced() << ":" << frame.refCount() << " / type: " << frame.pictureType() << endl;
}
if (frame || flushEncoder) {
do {
// Encode
Packet opkt = frame ? encoder.encode(frame, ec) : encoder.encode(ec);
if (ec) {
cerr << "Encoding error: " << ec << endl;
return 1;
} else if (!opkt) {
//cerr << "Empty packet\n";
//continue;
break;
}
// Only one output stream
opkt.setStreamIndex(0);
clog << "Write packet: pts=" << opkt.pts() << ", dts=" << opkt.dts() << " / " << opkt.pts().seconds() << " / " << opkt.timeBase() << " / st: " << opkt.streamIndex() << endl;
octx.writePacket(opkt, ec);
if (ec) {
cerr << "Error write packet: " << ec << ", " << ec.message() << endl;
return 1;
}
} while (flushEncoder);
}
if (flushEncoder)
break;
} while (flushDecoder);

The parts that are easy to get wrong:

  • Time base. The encoder was configured with a time base, and the frame must carry the same one before it is encoded: frame.setTimeBase(encoder.timeBase()). A mismatch produces packets with nonsensical timestamps, not an error.
  • Stream index. Packet::setStreamIndex() selects the output stream. With one stream it is 0.
  • Flushing. encoder.encode() without a frame drains the encoder, and a do/while is needed because one drain call can return several packets. The example drains inside the "decoder is at EOF" branch, which is where the last frames appear.
  • Writing. octx.writePacket(pkt) also accepts an error code. Writing is buffered; nothing is final until writeTrailer().

Finishing

writeTrailer() writes the container index and flushes the muxer. Without it, an MP4 file is unplayable even though the size looks plausible. If the muxer buffers packets, writePacket() with no arguments flushes them before the trailer.

Audio

av::AudioEncoderContext works the same way; set setSampleRate(), setChannelsCount(), setSampleFormat() and then open(). Convert the input samples to the encoder layout with av::AudioResampler before encoding, unless they already match.
