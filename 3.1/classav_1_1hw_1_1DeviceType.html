Detailed Description

Device types are looked up by name at runtime, so the wrapper works with FFmpeg versions that do not know newer enum values.

Examples
api2-hw-decode.cpp, api2-hw-encode.cpp, api2-hw-probe.cpp, api2-hw-scale.cpp, and api2-hw-transcode.cpp.
