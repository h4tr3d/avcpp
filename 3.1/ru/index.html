avcpp (Русский)

Обёртка над FFmpeg для C++17, превращающая C-API в типы с конструкторами, деструкторами и кодами ошибок.

FFmpeg — это набор C-библиотек с ручным управлением памятью, выходными параметрами и целочисленными кодами ошибок. avcpp сохраняет ту же модель — никаких скрытых копий и буферизации, о которой вы не просили, — но заворачивает её в RAII-типы в пространстве имён av.

Что покрыто

  • контейнеры и контексты форматов: демуксинг, муксинг, позиционирование;
  • кодеки и контексты кодеков: декодирование и кодирование, включая send/receive API;
  • кадры, аудиосэмплы и субтитры, включая текстовые и ASS-вставки и растровые прямоугольники;
  • графы фильтров: разбор из строки или сборка вручную;
  • программный ресайз видео и ресемплинг аудио;
  • аппаратное ускорение: устройства, аппаратные кадры, zero-copy декодирование и кодирование.

Справочник API

Справочник API генерируется из комментариев в исходниках и существует только на английском языке — это осознанное решение: комментарии пишутся один раз, и переводить их пришлось бы при каждом изменении кода.

  • Английский справочник API — отсюда можно перейти к группам core, avformat, codec, frame, filter, hw и subtitle.
  • Навигатор по API на русском — в планах (веха M2 плана документации).

Руководства

  • Начало работы — минимальная программа, которая декодирует файл.
  • Декодирование — пакеты в кадры, слив и метки времени.
  • Кодирование — кадры в пакеты и запись контейнера.
  • Ремиксинг — смена контейнера без перекодирования.
  • Фильтры — графы фильтров между декодером и кодировщиком.
  • Субтитры — текстовые, ASS- и растровые субтитры.
  • Аппаратное кодирование и декодирование — аппаратное декодирование, кодирование и нулевое копирование.
  • Обработка ошибок — договоренность OptionalErrorCode и категории ошибок.
  • Навигатор по API — какой тип для какой задачи, одной таблицей.
  • Сборка и установка — сборка, параметры конфигурации и интеграция.
  • Примеры — те же примеры, что и в английской версии, с исходным кодом.

Группы справочника API (на английском): core, avformat, codec, frame, filter, hw, subtitle.

Остальные страницы справочника — только на английском: комментарии в коде не переводятся.
