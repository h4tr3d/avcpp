Detailed Description

The context is reference counted with AVBufferRef. Copying the wrapper only adds a reference. Use raw() or bufferRef() to pass the context to FFmpeg.

Examples
api2-hw-decode.cpp, api2-hw-encode.cpp, api2-hw-probe.cpp, api2-hw-scale.cpp, and api2-hw-transcode.cpp.
